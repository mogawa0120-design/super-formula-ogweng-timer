鈴鹿 R11-12 情報共有タイマー（スマホ／タブレット アプリ版）配置手順
=====================================================================

■ このフォルダの中身（すべて同じ場所に置いてください）
  index.html              … アプリ本体（ログイン付き・日本語）
  sw.js                   … オフライン対応の仕組み
  manifest.webmanifest    … ホーム画面アプリの設定（名前：鈴鹿情報共有）
  icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png … アイコン

  ※ PC閲覧版は別ファイル「SUZUKA_R11-12_情報共有タイマー.html」です。
    こちらはログイン不要、ダブルクリックで開くだけ。アプリ版とは別物として扱ってください。


■ ログインID・パスワード（初期値）
  ID   ： ogw
  パス ： suzuka1122

  ▼ 変更したいとき
  index.html をメモ帳等で開き、下の2行（ファイル内「ログイン設定」の所）を書き換えて保存するだけ。
      var LOGIN_ID   = "ogw";
      var LOGIN_PASS = "suzuka1122";
  保存は必ず「UTF-8」で（Shift-JISだと文字化けします）。書き換えたら配置し直してください。

  ※ このログインは「関係者以外に開かせない」ための簡易ゲートです。URLを知っていて、
    かつID・パスを知っている人だけが時刻表を見られます。銀行レベルの強固な認証ではない点はご承知おきください。


■ 置き場所（GitHub Pages を想定。Thai版とは「別リポジトリ」にします）
  1. GitHub にログイン（Thaiと同じアカウントでOK）
  2. 新しいリポジトリを作成（例：suzuka-r1112-timer など、Thaiとは別の名前）
     ・推測されにくい名前にすると、より分離できます
  3. このフォルダ内のファイルを「そのまま全部」アップロード（フォルダ構成を変えない）
  4. リポジトリの Settings → Pages → Branch を main / (root) にして保存
  5. 数分後に発行される https://<ユーザー名>.github.io/<リポジトリ名>/ がアプリのURL

  ● 同一アカウント・別リポジトリの注意点
    - Thai版と中身・URL・ログインが別々なので、実運用上は干渉しません。
    - 唯一の弱点：あなたのGitHubプロフィールを辿ると、両方のリポジトリの“存在”は見えます。
      ただし中身はログインで保護されるので、URLを知られても時刻表は見られません。
    - 存在ごと隠したい場合は、リポジトリ名を分かりにくくするか、将来的に別アカウント/Privateをご検討ください。


■ メンバーの初回設定（1回だけ）
  1. 公開URLをスマホのブラウザで開く（iPhoneはSafari、AndroidはChrome）
  2. ID・パスでログイン（以後この端末では自動で省略されます）
  3. iPhone：共有ボタン（□↑）→「ホーム画面に追加」→「追加」
     Android：右上の ︙ →「ホーム画面に追加」または「アプリをインストール」
  4. ホーム画面の「鈴鹿情報共有」アイコンから1回開く（これでオフラインでも起動できます）
  5. 画面を1回タップ →「音声：準備OK」、iPhoneは本体の消音スイッチをOFFに
  6. 必要なら「🔊 音設定」で、鳴らしたい種別（情報共有・走行など）とアラーム音を選ぶ
  7. 走行中など画面を消したくないときは「📱 画面ON維持 ON」


■ スケジュールが変わったとき
  ・担当者がPC版またはアプリで「✎ 編集」→ 時刻を修正 →「変更をHTMLとして保存」
  ・できた index.html を、GitHub の同じ場所に上書きアップロード
  ・sw.js の1行目付近  const VERSION = 'suzuka-r11-12-v1';  の数字を v2, v3… と上げて保存・アップロード
  ・メンバーは電波のある所でアイコンを開くだけで最新版になります


■ 音について（③④）
  ・「🔊 音設定」で、情報共有以外（走行・黄色SW連絡・スタート進行など）も
    チェックを入れればアラームが鳴ります。鳴らす種別は自由にON/OFFできます。
  ・アラーム音は6種類（ビープ／ピッピ／チャイム／ベル／ブザー／マリンバ）から選べます。「▶試聴」で確認。
  ・チェックした種別の「5分前・1分前・開始」に鳴ります（上部「アラート音 ON」が必要）。
  ・ブラウザの仕様上、PC・スマホともに本体の“システム音そのもの”は使えないため、内蔵音から選ぶ方式です。
